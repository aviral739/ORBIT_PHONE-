# ORBIT_PHONE Setup

This directory contains the setup documentation and dependency lists for ORBIT_PHONE development.

Please refer to [`setup_instructions.md`](setup_instructions.md) for a step-by-step guide on how to clone, inspect, and run the verified components of this repository (Simulator, Configurations, and SQL Database Schemas).

**Current Project Status:**
The project is currently focused on Python-based simulation and contract definition. Full Kotlin Android app compilation is not yet supported in this branch.
